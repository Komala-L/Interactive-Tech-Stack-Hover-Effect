# Interactive-Tech-Stack-Hover-Effect

A modern and minimal custom cursor interaction project built using HTML, CSS, and JavaScript.
This project replaces the default cursor with a smooth, animated circular element that follows mouse movement and creates a visually appealing blend effect.

## 🛠️ Tech Stack
🔹HTML5 <br>
🔹CSS3 <br>
🔹JavaScript (Vanilla JS) <br>

## 🎯 Features
🔹Custom circular cursor <br>
🔹Smooth mouse tracking animation <br>
🔹Blend mode effect using mix-blend-mode: difference <br>
🔹Clean and minimal UI <br>
🔹Fully responsive layout <br>

## ⚙️ How It Works
🔹A div element is used to create a custom cursor. <br>
🔹JavaScript listens to the mousemove event on the main container. <br>
🔹The cursor position updates dynamically based on mouse coordinates. <br>
🔹CSS mix-blend-mode: difference creates a color inversion effect when the cursor moves over elements. <br>
